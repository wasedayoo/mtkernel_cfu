
 SimRV - High-Performance RISC-V Functional Simulator 

Usage: /home/archlab/ltrunk/workspace/tools/SimRV/build/rv32-release/SimRV [options]

Required:
  -m, -k, -i, --image, --kernel <FILE> Memory image file to load

Devices and Files:
  -d, --disk <FILE>      Disk image file (enables block storage virtio-disk)
  -f, -c, --fdt, --dtb <FILE> Device-tree binary file (FDT / DTB configuration)

Execution Control (runs on high-performance simrv::pipeline engine):
  -s, -e, --steps <N>    Stop execution after N instructions
  -t, -l, --timer <N>    Enable timer after N cycles (CLINT ticker threshold)
  -b, -a, --baremetal         Binary mode (raw baremetal execution, start_pc=0)
  -u, --tui                  Enable interactive TUI split-screen monitor dashboard
  --high-contrast, --contrast Toggle TUI colors to high-contrast palette
  -C, --cycle-accurate, --ca Enable structural cycle-accurate performance simulation mode
  --high-accuracy, --accuracy-mode Alias for --cycle-accurate (High-Accuracy Mode)
  --high-performance, --perf-mode, --ia Enable optimized simulation mode bypassing caches/coroutines (default)
  --cpu-config <FILE>    Load CPU latency configuration from a text file
  --misa <PROFILE>      Select CPU MISA profile: rv32i | rv32imac | rv32gc

Tracing and Debug (outputs generated inside trace/ subdirectory):
  -r, --trace-range <BG> <EN> Write trace snapshot to trace/trace.txt for instruction range
  --trace-pc-period <N>   Generate periodic trace/tracepc.txt every N instructions
  --trace-bpred           Generate trace/bpred.txt branch prediction trace
  -I, --dump-init <N>     Dump initial architectural and TLB state artifacts at cycle N
  -g, -v, --debug, --verbose Enable verbose debug logging output
  -M, --log-mmio              Enable interactive disk/console MMIO transaction logging
  --trap-log <FILE>     Write comprehensive trap/SBI diagnostic logs to file
  --instmix               Write instruction mix metrics report to trace/instmix.txt on exit

ISA Test Mode:
  -T, --tohost-monitor    Enable riscv-isa-tests tohost termination monitoring
  -H, --tohost-addr <AD> Custom custom tohost device MMIO address for -T

Miscellaneous / Co-Simulation:
  -h, --help        Show this colorized dashboard menu and exit
  --version         Show compiler-injected version details and exit
  -G, --gdb                  Enable GDB RSP stub (waits for client before running)
  -p, --port, --gdb-port <PORT> Override GDB stub listen port (default: 1234)
  --lockstep         Enable Spike lockstep instruction-by-instruction verification
  --spike-bin <PATH> Path to spike binary for lockstep (default: spike in PATH)

Numeric values accept standard scaled suffixes: k/K (1e3), m/M (1e6), g/G (1e9)

Examples:

  /home/archlab/ltrunk/workspace/tools/SimRV/build/rv32-release/SimRV --image linux-images/rv32/fw_payload.bin -u
